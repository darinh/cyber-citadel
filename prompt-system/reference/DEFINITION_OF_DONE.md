# Definition of done

A course is complete only when all applicable items below are true.

## Learning design

- Audience, prior knowledge, use context, terminal performance, conditions, and success criteria are explicit.
- Every truth fact is required or excluded with a reason.
- Required facts map to measurable objectives and rendered beats.
- Objective prerequisites are taught first.
- Evidence and practice match the objective’s cognitive demand.
- Complex skills include modeling and scaffolded-to-independent practice.
- Every practice has learner commitment time and explanatory feedback.
- Apply-level and higher objectives include a genuinely novel transfer task.
- Later episodes/follow-ups retrieve earlier objectives where retention matters.
- Narrative, avatars, music, and decorative media are absent unless they have an approved purpose.

## Accuracy, media, and accessibility

- Fact, quote, title, and citation checks pass against `truth.json`.
- Every explanatory visual has purposeful alt text.
- Every image/video resolves through `assets/media.json` with complete provenance/license metadata.
- Chart values and visually implied claims are sourced.
- Captions are accurate, readable, and do not obscure evidence or controls.
- Visual meaning does not rely only on color.
- Credits and notices include all third-party media.

## Script and production

- Instructional, fact, IP, and craft gates have zero blocking findings.
- A multi-model council reviewed the learning blueprint and final script.
- Narration is complete, natural, and correctly pronounced.
- Visuals complement rather than substantially duplicate narration.
- One representative pilot was rendered and inspected before any batch.
- Final files use the two-pass mux and pass final-mp4 verification.
- Incremental cache behavior was exercised for changed text/media.

## Interaction and package

- Quiz buttons are clickable from first appearance and only the buttons are active.
- Hotspots align after resize; hover, pointer, keyboard focus, pause/resume, and reveal work.
- Practice cues contain prompt, work interval, model answer, and feedback.
- Player uses a range-capable HTTP server.
- Episodes, captions, cues, transcripts, references, and credits resolve from the package manifest.

## Effectiveness evidence

Structural checks do not prove learning. Record, when available:

- subject-matter expert approval;
- representative learner usability findings;
- objective-level performance or transfer results;
- revisions made from that evidence.
