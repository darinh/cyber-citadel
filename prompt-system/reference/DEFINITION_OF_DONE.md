# Definition of Done

Before telling a user a course is ready, verify the shipped local course end to end.

## Required gates
Run from `prompt-system/`:

```bash
python engine/gates/verify_facts.py course/scripts/ep01.json
python engine/gates/lint_prompts.py
python engine/gates/lint_script.py ep01
python engine/build_episode.py course/scripts/ep01.json
python engine/gates/verify_episode.py ep01
python engine/package.py
python serve.py
```

For multiple episodes, run the fact/script gates and `verify_episode` for each episode id.

## Checklist
- `verify_facts` passes for every authored episode.
- `lint_prompts` reports no blocking existing-IP/style-imitation problems.
- `lint_script` reports no blocking script or quote problems.
- One episode was rendered first and spot-checked before bulk rendering.
- Every final MP4 passes `verify_episode OK`.
- Interactive quiz hotspots line up with the rendered option boxes.
- Quiz narration reads question, all options, correct answer text, and why.
- `engine/package.py` completes and link-check is clean.
- Music is sourced and CC-BY items are attributed in `THIRD_PARTY_NOTICES.md`.
- Vendored and third-party notices are current.
- `plan.md` reflects the current project state and next steps.
- There are zero references to protected worlds, named characters, trademarks, or artist styles.
- The user can double-click `play.cmd` or run `python serve.py` and watch locally.
## Package verification
- `watch.html`, `index.html`, `serve.py`, and `play.cmd` are present after packaging.
- Episode `.mp4`, `.srt`, and `.cues.json` files exist under `course/episodes/`.
- The `.cues.json` quiz `opt_rects` align with the video boxes.
- Posters/manifests generated by packaging point to existing files.
- Local playback uses the range server, not direct `file://` URLs.

## Documentation state
- `THIRD_PARTY_NOTICES.md` lists CC-BY music and vendored font notices.
- `plan.md` records what shipped and any known follow-up.
- Reference docs and schemas match the engine commands and fields.
- No content-only work changed files under `engine/`.
